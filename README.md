# Team Kyhera Cadoret — Site officiel

Site vitrine officiel de Kyhera Cadoret, championne de France de Kick-Boxing UFSC 2026.

## Contenu

- Présentation de Kyhera
- Palmarès et statistiques
- Galerie photos
- Packs de sponsoring
- Dossier de sponsoring
- Coordonnées et réseaux sociaux

## Mise en ligne avec GitHub Pages

1. Téléversez tous les fichiers et dossiers de ce projet dans votre dépôt GitHub.
2. Dans **Settings > Pages**, choisissez **Deploy from a branch**.
3. Sélectionnez la branche **main/principal** et le dossier **/(root)**.
4. Enregistrez, puis attendez quelques minutes.
